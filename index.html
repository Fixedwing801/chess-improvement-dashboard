Current training priorities

Provisional diagnosis

1. Middlegame decision-making

Current phase averages show the highest CPL in the middlegame. Practise identifying opponent threats, comparing candidate moves and checking forcing replies before committing.

2. Review critical positions

Prioritise positions where the engine identifies a substantial evaluation swing. Reconstruct the thought process before viewing the engine line, then record the missed cue.

3. Blitz calculation discipline

Blitz is the largest sample and the most representative time control in the current dataset. Use short calculation routines rather than relying on intuition alone.

4. Build a usable opening set

Review frequently played lines first. Focus on plans, typical piece placement and recurring tactical ideas rather than memorising long engine variations.

These priorities are provisional. The sample is incomplete and short engine searches can mis-rank moves. They will be refined as historical coverage and deeper validation improve.

Methodology, privacy and limitations

Game analysis uses Stockfish through an automated pipeline. Centipawn loss (CPL) is an estimate from short engine searches, not Chess.com accuracy. Mistake categories are heuristic; very large evaluation swings require deeper verification.

This public page contains aggregate statistics only. It excludes game PGNs, move histories, opponent identities, individual positions, training exercise FENs and private account data.

Dashboard data is loaded from a separate, sanitised JSON file. If that file cannot be reached, the page will display an error rather than invent figures.
