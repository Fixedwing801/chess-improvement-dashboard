Methodology and limitations

Analysis uses Stockfish through an automated pipeline. Centipawn loss is an estimate from short engine searches, not Chess.com accuracy. Mistake categories are heuristic. Engine scores can be sensitive to position complexity, forced mates and search depth.

This page intentionally contains aggregate statistics only. It excludes game PGNs, move histories, opponent identities, individual positions, account credentials and private training records.
