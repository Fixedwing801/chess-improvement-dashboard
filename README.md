# Chess Improvement Lab Dashboard

Public, aggregate-only view of the Chess Improvement Lab.

- The source games, PGNs, move-level analysis, opponent identities and detailed exercises remain in the separate private repository.
- This repository is intended to contain only the rendered dashboard and approved aggregate metrics.
- The dashboard is a static, mobile-responsive HTML page.

## GitHub Pages

The site is deployed from GitHub Actions. Once Pages is enabled for this repository, the workflow publishes `index.html`.
